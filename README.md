# Student Organizer (Kotlin + Jetpack Compose)

This is a UI-only student organizer demo. It uses sample data and in-memory state; it does not use an API or database.

## Open in Android Studio
1. Extract this ZIP to a normal folder.
2. In Android Studio choose **File → Open** and select the extracted project folder (the folder containing `settings.gradle.kts`).
3. If asked for a Gradle JDK, choose **Embedded JDK**.
4. Let Gradle sync finish. The project is configured for Gradle 8.9 with Android Gradle Plugin 8.7.3.
5. Select an emulator/device and press **Run ▶**.

If Android Studio offers to upgrade Gradle automatically, decline for now and keep the project wrapper version.
